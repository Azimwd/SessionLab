# Отдельные режимы атак

В редакторе атаки и атакующего заклинания («Как применяется» → «Бросок атаки») добавлен блок «Режим каждой атаки».

Для каждого отдельного броска можно выбрать обычную атаку, преимущество или помеху. Например, при количестве бросков 3: первая — преимущество, вторая — обычная, третья — помеха. По умолчанию неуказанные режимы обычные. Настройка сохраняется в самом действии.

Кнопка «Настроить дополнительный бросок» позволяет заранее настроить дополнительные лучи от высокой ячейки или усиления заговора. Она не увеличивает количество самих атак: их число по-прежнему определяется настройками способности и уровнем ячейки. Максимум 20 режимов.

Быстрое применение с обзора и обычное применение из списка используют сохранённые настройки. В полном списке можно явно выбрать разовый общий режим атаки; такой выбор заменяет режимы всех бросков для этого применения. По умолчанию выбран пункт «Из настроек каждой атаки». Общий режим проверок листа больше не подменяет настройки атак при быстром применении.

Для заклинаний со спасброском и автоматическим эффектом настройки атаки не показываются: они относятся к броскам на попадание, а не к кубикам урона или спасброскам выбранных целей.

В DMHub откройте редактирование действия: раздел «РЕЖИМ КАЖДОЙ АТАКИ». Режимы сохраняются на сервере и работают при применении из мода. Общий переключатель «Проверки» относится к проверкам, а не к атакам.

## Установка

Обновите backend и frontend, выполните в окружении backend:

```sh
python manage.py migrate
```

Новая миграция: `0019_characterability_roll_modes`. Пересоберите frontend и перезапустите сервер. Для DMHub замените Main мода листа файлом `scripts/SessionLabSheet_ASCII.lua`, сохранив URL и TOKEN. Мод комнаты менять не требуется. Seed запускать не нужно.

## API

У способности добавлено поле `roll_modes`, список до 20 значений `normal`, `advantage`, `disadvantage`. Индекс 0 соответствует первому броску. Пустой список означает обычные атаки.

При применении приоритет: переданный `roll_modes` → явно переданный общий `mode` → сохранённый `roll_modes`. Неуказанные в списке позиции обычные. Параметры запроса не изменяют сохранённые настройки. Старый API с общим mode сохранён. Для каждого броска сервер отдельно генерирует d20, выбирает максимум/минимум и вычисляет критическое попадание. Результаты фиксируются в снимке события. Повтор запроса с тем же ключом не перебрасывает кубики.
