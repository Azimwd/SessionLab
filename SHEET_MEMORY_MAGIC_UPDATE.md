# Последний открытый лист и основная характеристика магии

## Что изменилось

Сайт запоминает последний доступный открытый лист отдельно для пользователя, кампании и режима мастера/игрока. При возвращении в раздел открываются этот лист и его папка. Прямая ссылка с character имеет приоритет. Удалённые и недоступные листы не восстанавливаются. Запоминание действует в том же браузере.

На обзоре в блоке «Магия» и на вкладке заклинаний доступен выбор «Основная характеристика магии»: сила, ловкость, телосложение, интеллект, мудрость, харизма. Настройка сохраняется обычным автосохранением листа.

В редакторе заклинания добавлен выбор источника характеристики: основная из листа либо отдельная характеристика этого заклинания. Заклинания, использующие лист, при смене основной характеристики меняют бонус атаки, СЛ спасброска и добавляемый модификатор урона/лечения. Обычные атаки используют собственную характеристику. Фиксированная СЛ из правил отдельных заклинаний сохраняется.

Новые заклинания из каталога и из редактора используют основную характеристику листа. Миграция связывает с листом старые заклинания, характеристика которых совпадала с основной; остальные остаются отдельными исключениями. При необходимости источник можно изменить в редакторе.

## Установка

Обновите backend и frontend из архива. Выполните в окружении backend:

```sh
python manage.py migrate
```

Новая миграция: `0017_characterability_use_spell_ability`. Пересоберите frontend и перезапустите backend. Seed не требуется.

Если используете редактор листа в DMHub, обновлённый `scripts/SessionLabSheet_ASCII.lua` поддерживает тот же выбор источника характеристики для заклинания. Сохраните свои URL и TOKEN. Мод комнаты менять для этого обновления не нужно.

## Закреплённые листы

Откройте нужного персонажа и нажмите «Закрепить лист» рядом с переключателем персонажей. Над выбором папки появится раздел закреплённых листов: имя, папка и быстрый переход одним нажатием. Активный лист выделяется. Можно убрать закрепление кнопкой рядом с именем или кнопкой «Открепить лист».
Список сохраняется в localStorage отдельно для аккаунта, кампании и режима мастера/игрока. Это настройка текущего браузера. Недоступные и удалённые персонажи не отображаются; закрепление не меняет права доступа. Длинный список закреплений прокручивается внутри блока. Последний открытый лист продолжает запоминаться отдельно.
Для установки этой правки достаточно обновить и пересобрать frontend. Backend, миграции и Lua менять не нужно.
