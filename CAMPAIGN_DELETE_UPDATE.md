# Удаление кампаний

В разделе «Кампании» на карточке владельца появилась кнопка «Удалить».
Подтвердите действие точным названием кампании. Второй мастер и игроки не могут удалять чужие кампании.
После удаления кампания пропадает у всех участников; приглашение больше не работает, доступ через сайт, комнату и ключи DMHub закрывается.
Удаление логическое: связанные листы, история и финансовые записи остаются в базе для сохранения целостности. Восстановления через интерфейс нет.
Повторный DELETE владельца безопасен и не создаёт повторных записей удаления.

## Установка

Обновите backend и frontend из архива. В окружении сервера выполните:

```sh
python manage.py migrate
```

Новая миграция: `0016_campaign_deleted_at`.
Затем пересоберите frontend обычным способом (`npm ci`, `npm run build`) и перезапустите backend.
Существующие кампании продолжают работать; seed запускать не требуется.

## API

`DELETE /api/campaigns/<id>/`

```json
{"confirm_name":"Точное название кампании"}
```

Обычная сессионная авторизация и CSRF. Ответ: `{"data":{"id":1,"deleted":true},"error":null}`.
