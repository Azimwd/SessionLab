# Настройки эффектов атак

## Установка
Обновите исходники из полного архива. На сервере выполните `python manage.py migrate` (миграция 0020_attack_effects), пересоберите frontend командой `npm run build`. Для DMHub замените Main обоих модов содержимым SessionLabSheet_ASCII.lua и SessionLabRoom_Main.lua, сохранив свои URL и TOKEN.

## Использование
В редакторе оружейной атаки добавьте пресет эффекта или настройте свой. При броске выберите включённые эффекты; после броска в панели нанесения урона можно отключить отдельные эффекты для каждого попадания. Это позволяет сохранить Удар Суда для нужной атаки, например критической. Неиспользованный эффект не расходует лимит применения.

Удар Суда: с 3 уровня 1d8, с 7 — 1d10, с 10 — 1d12, с 15 — 2d10. При критическом попадании обычное удвоение костей сохраняется, а повышение добавляется сверху: 1d8 → 2d8 + 1d10; 2d10 → 4d10 + 2d12. Штраф за критический провал не реализован по вашему решению. Рост определяется общим уровнем персонажа.

Тип Удара Суда меняется на некротический, если перед применением попадания у цели строго меньше половины максимальных HP. Ровно половина не меняет тип. Сервер проверяет это без раскрытия HP игроку. Каждый положительный компонент отдельно учитывает сопротивления, иммунитеты и уязвимости цели. Отрицательный эффект уменьшает основной урон оружия до применения защиты; результат не ниже нуля и не лечит цель.

Оценка Жизни: игрок выбирает объявленный мастером вариант +1d4 или −1d4. Варианты одной группы нельзя включить одновременно.

Печать Возмездия: выберите цель перед броском. Первая атака по этой цели за ход получает преимущество (помеха отменяет его); право первой атаки расходуется при броске, независимо от попадания. Первый применённый дополнительный урон +1d8 имеет отдельный лимит. Нанесение урона привязано к выбранной цели.

Одинаковые ID эффекта на разных оружиях используют общий лимит. Сохранённый бросок содержит снимок настроек: редактирование способности не меняет его. Во время боя границы хода берутся из инициативы; вне боя используйте кнопку «Новый ход вне боя». Повторная отправка одного запроса не наносит урон повторно.

## Ручное управление
Мастер определяет грешность/невинность. Длительность Печати, использование один раз за долгий отдых, объявление смерти цели, лечение после смерти, заключительный спасбросок Мудрости и истощение остаются ручными. Автоматического таймера и списания зарядов Печати нет.

## Проверки
Пройдены серверные регрессионные тесты, 18 тестов новых эффектов, frontend-тесты и production build, Lua-проверки листа и комнаты. Проверки Lua выполнялись с тестовым окружением; запуск в живом клиенте DMHub не проверен.
