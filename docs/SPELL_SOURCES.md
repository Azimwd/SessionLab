# Источники справочника заклинаний

Справочник охватывает **319 заклинаний SRD 5.1 (редакция 2014)**. Он не включает заклинания из книг, не вошедших в SRD, и не заменяет правила редакции 2024.

Данная работа включает материалы из System Reference Document 5.1 («SRD 5.1») от Wizards of the Coast LLC, доступного по адресу https://dnd.wizards.com/resources/systems-reference-document. SRD 5.1 лицензирован под лицензией Creative Commons Attribution 4.0 International, доступной по адресу https://creativecommons.org/licenses/by/4.0/legalcode.

Русские описания и параметры заклинаний адаптированы из [перевода SRD 5.1 проекта OmnisGM](https://github.com/OmnisGM-App/OmnisGM-Rules/blob/main/src/dnd/srd-5.1/ru/10_Spells.md), © 2026 Petr Radilov / OmnisGM; [rules.omnisgm.com](https://rules.omnisgm.com). Перевод опубликован на условиях [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Изменения SessionLab: сопоставление с уникальными идентификаторами каталога, удаление Markdown-разметки при отображении, сохранение прежних русских названий для совместимости с уже созданными листами. Источник и скрипт импорта: `scripts/import_srd51_ru.py`.

Тексты и поля «наложение», «дистанция», «компоненты», «длительность» доступны по-русски для всех 319 записей. Отметка `verified` относится к проверенной числовой формуле, а не к полноте автоматизации всех игровых последствий. Для всех заклинаний сервер вычисляет СЛ и бонус атаки, учитывает ячейку; для 69 записей настроены проверенные числовые броски. Повторные срабатывания поддерживаемых заклинаний бросаются отдельно без второго расхода ячейки. Воля целей, перемещение, время, иммунитеты, изменение хитов и прочие особые эффекты всё ещё требуют решения за столом.
