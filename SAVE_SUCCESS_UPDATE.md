# Урон при успешном спасброске

В редакторе действия при применении «Спасбросок цели» появилось поле «Урон при успешном спасброске»:

- По правилам каталога (для собственного заклинания без каталога — 0).
- Нет урона.
- Половина урона, с округлением вниз.
- Полный урон.

При провале применяется весь выпавший урон. Например, для результата 15 настройка «Половина» даёт 7 при успехе и 15 при провале. После спасброска учитываются защиты цели. Выбор сохраняется в конкретном действии и применяется ко всем его отдельным броскам.

Чтобы настроить собственное заклинание: откройте его редактирование, выберите «Спасбросок цели», установите «Половина урона» в новом поле и сохраните. Затем выполните новый бросок. Уже сохранённые результаты остаются неизменными.

## Установка

Обновите backend и frontend, выполните в окружении backend:

```sh
python manage.py migrate
```

Новая миграция: 0018_characterability_save_success. Пересоберите frontend и перезапустите backend. Запуск seed не требуется.

Существующие заклинания сохраняют прежние правила: новое поле по умолчанию имеет значение rules. Каталожная половина/полный урон сохраняются, собственные заклинания по умолчанию дают 0 при успехе до изменения настройки.

Для редактирования этого параметра в DMHub замените Main мода листа файлом scripts/SessionLabSheet_ASCII.lua, сохранив URL и TOKEN. Поле называется «Урон при успехе». Мод комнаты уже использует рассчитанные сервером суммы успеха и провала и не требует замены.

## API

У CharacterAbility добавлено поле save_success: rules | none | half | full. POST/PATCH способностей принимают его через обычную проверку прав и версии. Сервер записывает failed_damage и success_damage в неизменный результат броска, а применение урона использует этот сохранённый результат.
